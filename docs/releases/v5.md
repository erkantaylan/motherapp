# motherapp v5

Notifications move into motherapp itself, with a history panel, sounds and a tray icon. The tmux
page can now type into a session.

## Install

```sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/erkantaylan/motherapp/main/scripts/get.sh)"
```

To update an install: `motherapp install`, or Settings → Update now.

## What's in it

- **One notification service.** Tools hand their notifications to the core with `tool.notify`, and
  the core shows the popup. The tmux tool no longer sends its own. Popups carry the motherapp icon
  and name, and GNOME lists motherapp under Settings → Notifications, so it can be switched off
  there.
- **Launcher.** motherapp is in the app grid and opens the panel in the default browser.
- **Bell and history.** A strip on the right edge of every page has a bell with a count of new
  notifications. A click docks the history beside the page (in a window of 1480 px or wider; it
  lies over the page in a narrower one), another click hides it. The last 200 are kept, in memory.
- **Settings.** Mute all, a switch per tool, and per kind of notification a switch and a sound,
  chosen from the system's stock sounds, with a play button. tmux plays `bell` when a session
  finishes and `window-attention` when one is waiting on you.
- **Tray icon.** Shows that motherapp is running, and turns into a warning when a tool has
  crashed. Its menu has Open motherapp, Mute notifications and a status line. It needs the
  AppIndicator extension and `gir1.2-ayatanaappindicator3-0.1`; `motherapp doctor` says if
  something is missing. Settings → Desktop turns it off.
- **Send text to a tmux session.** A box under the preview, and `tmuxctl send <session> <text>`.
  The text is typed first and Enter is pressed as a separate key, which is what a Claude session
  needs to submit. Text with line breaks goes in as a paste. Only from the computer itself, not
  from the local network.

## For tool authors

- Declare notification kinds in the manifest (`notifications: [{ id, label, sound? }]`) and call
  `tool.notify({ kind, title, body? })`. See `docs/extension-contract.md`.
- `MOTHERAPP_TMUX_NOTIFY` is gone. `MOTHERAPP_NOTIFY=off` and `MOTHERAPP_TRAY=off` keep a test
  core off the desktop.
