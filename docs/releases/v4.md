# motherapp v4

A small polish release for the tmux dashboard.

## Install

```sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/erkantaylan/motherapp/main/scripts/get.sh)"
```

To update an install: `motherapp install`, or Settings → Update now.

## What's in it

- **Full width.** The tmux page uses the whole window, so on a wide screen the details scrollbar sits
  at the screen edge. Other pages keep their width limits.
- **Last message.** It grows to its full length, with no scrollbar of its own.
- **Less clutter.** The session count line is gone. The row above the list now appears only for an
  error or the "Needs you" strip, and takes no room otherwise.
