# motherapp v3

A layout release. Every page gets a smaller header that stays in place, and the tmux dashboard
stops scrolling as one long page.

## Install

```sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/erkantaylan/motherapp/main/scripts/get.sh)"
```

To update an install: `motherapp install`, or Settings → Update now.

## What's in it

- **Page header.** On every page it now stays at the top while you scroll. It's more compact, with
  a clear line under it that runs the full width.
- **tmux dashboard.** On a wide screen the page no longer scrolls. The session list and the selected
  session each have their own scrollbar, and the preview keeps a fixed height.
- **CPU page.** The sticky Live column and die details now stop below the header.
