# UI polish: still pages, clickable rows, fading dots (2026-10-20, sub-agent: issues #12, #14, #15)

Fixed in the core renderer, so every tool gets it: bound text keeps its line (`reserve`),
list-row sublabels are one line, a row's name selects its single radio, and a green status dot
fades after 2 s.

## Lessons

- [cloud] The web tests have no DOM (no jsdom, root tsconfig without `dom`). Adding a DOM library
  would touch `package-lock.json`, which parallel agents also change. → Put the decision in a
  DOM-free module and test that: `textWidget.ts` (`textView`), `rowSelect.ts` (`rowSelectRadio`),
  `DotStatus` in `actionRunner.ts` (timers tested with `t.mock.timers.enable({ apis: ["setTimeout"] })`).
  Then check the real behaviour in Chromium with Playwright.
- [cloud] A layout-shift check that works: in the page, record `getBoundingClientRect().top` of
  every element under `.content`, compare on each `requestAnimationFrame` while
  `page.mouse.down/move/up` drags a slider, and report the largest change. Give the fake
  `ddcutil` a `sleep 0.3` wrapper so writes overlap the way they do on the machine. Against the
  old build (`git archive a1b9430` into the scratchpad, with `node_modules` symlinked to the
  worktree's) the check showed the monitor list jumping 48 px. After the fix: 0 px.
- [cloud] The worktree had no `node_modules`, so Node resolved packages from the main
  checkout's, and `@motherapp/*` pointed at the **main checkout's** sources, not the worktree's. →
  Run `npm ci` (Node 24) in the worktree before testing changes to `packages/`.
- [both] `.w-text.reserve { min-height: 1lh }` keeps one line only. Text that wraps onto a second
  line still pushes things down. → Keep text that changes during a drag short, or below the
  controls (brightness's `allNote` is now last on the page).
- [both] Bound text now reserves its line by default, so the Audio and tmux pages show one empty
  line under the header where `status` would go. That's deliberate: `status` can appear while
  sliders are in use. Tools opt out with `reserve: false` (brightness does for `warning` and
  `status`, which only change at startup or while there are no monitor rows).
- [both] Bootstrap's `[hidden] { display: none !important }` lives in an earlier cascade layer
  than `@layer custom`, and `!important` reverses layer order, so it still beats our
  `display: block` on `.row-sub`.
- [both] For the fade, `DotStatus` emits `idle` after 2 s and `statusDot()` keeps
  `data-status="set"` (the green) and adds `data-faded`. The opacity transition is only on
  `[data-faded]`, so a new status shows instantly while the old one fades out.
- [cloud] The fake PipeWire's Test L/R fails in the container (no `sound-theme-freedesktop`), so
  "Test L/R doesn't select the row" was only checked as "no `wpctl set-default`, radio unchanged".
